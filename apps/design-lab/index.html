Design lab

Static review sheets for the token system. Open any page directly from the filesystem — there is no dev server and no build step beyond pnpm --filter @fluvy/tokens build, which writes the stylesheet and the palette data these pages read. Add ?palette=<name>&mode=<light|dark>&width=<px> to render a single framed sheet; that is exactly what the screenshot tool does.

  • Palette gallery — the taste sheet: each palette on one dashboard, light and dark side by side
  • Palette sheets — the spec sheet: every token and every measured ratio
